# Парсер расписания miterra.chuc.ru

Этот проект представляет собой парсер расписания с сайта miterra.chuc.ru и веб-интерфейс для отображения данных.

## Возможности

- Автоматическая авторизация на сайте miterra.chuc.ru
- Парсинг расписания групп
- Парсинг расписания преподавателей
- Веб-интерфейс для просмотра расписания
- Автоматическое обновление данных каждые 5 минут
- API для получения данных

## Установка

1. Убедитесь, что у вас установлен Python 3.7 или выше
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

1. Запустите веб-сервер:

```bash
python app.py
```

2. Откройте браузер и перейдите по адресу: http://localhost:5000

## Структура проекта


## API Endpoints

- `GET /` - Главная страница
- `GET /api/schedule` - Получить все данные расписания
- `GET /api/groups` - Получить список групп
- `GET /api/teachers` - Получить список преподавателей
- `GET /schedule/group/<group_name>` - Расписание конкретной группы
- `GET /schedule/teacher/<teacher_name>` - Расписание конкретного преподавателя
- `GET /api/refresh` - Принудительное обновление данных

## Особенности

- Данные обновляются автоматически каждые 5 минут в фоновом режиме
- Поддерживается кодировка Windows-1251 (как на оригинальном сайте)
- Веб-интерфейс адаптивный и работает на мобильных устройствах
- Есть кнопка принудительного обновления данных
