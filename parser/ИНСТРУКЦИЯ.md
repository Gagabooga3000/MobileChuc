# Инструкция по запуску парсера расписания

## Быстрый запуск

1. **Двойной клик на файл `start.bat`** - автоматически установит зависимости и запустит сервер

2. **Или запустите вручную:**
   ```bash
   pip install -r requirements.txt
   python app.py
   ```

3. **Откройте браузер** и перейдите по адресу: http://localhost:5000

## API Endpoints

- `GET /` - Главная страница
- `GET /api/schedule` - Все данные расписания
- `GET /api/groups` - Список групп
- `GET /api/teachers` - Список преподавателей
- `GET /schedule/group/<название_группы>` - Расписание группы
- `GET /schedule/teacher/<имя_преподавателя>` - Расписание преподавателя
- `GET /api/refresh` - Принудительное обновление

## Устранение проблем

**Если парсер не работает:**
1. Проверьте подключение к интернету
2. Убедитесь, что сайт miterra.chuc.ru доступен
3. Проверьте правильность логина и пароля в файле `parser.py`

**Если веб-сервер не запускается:**
1. Убедитесь, что Python установлен
2. Установите зависимости: `pip install -r requirements.txt`
3. Проверьте, что порт 5000 свободен
